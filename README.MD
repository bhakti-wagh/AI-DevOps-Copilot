# AI DevOps Copilot

AI DevOps Copilot is a tool that analyzes DevOps errors and provides AI-based suggestions to fix them.

## Features
- Detects DevOps errors
- AI-powered troubleshooting suggestions
- API testing interface
- Simple web dashboard

## Tech Stack
- Python
- Flask
- OpenAI API
- HTML / JavaScript

## Run Project

Install dependencies:

pip install -r requirements.txt

Run application:

python app.py
